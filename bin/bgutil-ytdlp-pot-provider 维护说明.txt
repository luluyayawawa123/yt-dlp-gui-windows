bgutil-ytdlp-pot-provider 维护说明
==============================

当前内置版本（2026-09-21）：官方 Provider server 和插件均为 2.0.0，bgutils-js 为 4.0.3，随软件携带的 Deno 为 2.9.7。

一、组件与位置
--------------
需要生成 YouTube PO Token 时，软件会调用 bgutil 脚本：Deno 运行 server/src/generate_once.ts，再由插件把 Token 交给 yt-dlp。这里不需要常驻的 HTTP 服务。

Provider server：bin/bgutil-ytdlp-pot-provider/server/
插件 ZIP：bin/yt-dlp-plugins/bgutil-ytdlp-pot-provider.zip
Deno：bin/deno.exe

server 与插件必须版本配套，不要只替换其中一个，也不要单独升级 bgutils-js。PO Token 并不能保证消除所有 403，也无法保证绕过 YouTube 的登录验证；问题背景见项目根目录《YouTube上游PO Token修复跟踪事项.txt》。

二、升级方法
------------
官方仓库：https://github.com/Brainicism/bgutil-ytdlp-pot-provider
官方发布：https://github.com/Brainicism/bgutil-ytdlp-pot-provider/releases

1. 先查看目标版本的官方 README 和运行要求。2.0.0 要求 yt-dlp 不低于 2025.05.22、Deno 不低于 2.0.0；用 npm 安装依赖时，Node.js 需为 22 或更新版本。
2. 从同一个版本标签取得 server 源码和发布附件 bgutil-ytdlp-pot-provider.zip，分别替换到上面列出的两个位置。
3. 在项目的 server 目录运行 npm.cmd ci --omit=dev --no-fund --no-audit。它会根据官方 package-lock.json 重建 node_modules，不必手动删除旧目录。
4. 确认插件与脚本显示的版本一致，再分别测试普通下载、播放列表下载和绿色版。

三、移动目录与打包
------------------
build.py 会在绿色版的打包目录中重建可迁移的 node_modules。因此，绿色版解压后可以移动或改名，通常无须再运行 deno install。如果移动开发目录后依赖损坏，可在新位置的 server 目录重新运行上面的 npm ci 命令。

打包电脑需要 Node.js 22 或更新版本来运行 npm ci；绿色版用户不必安装 Node.js 或 Deno。绿色版必须保留 bin/deno.exe。这个文件没有纳入 Git，执行 Git 还原也不会把它恢复出来。

四、升级后检查
--------------
1. 确认 verbose 日志中的 bgutil:script-deno 版本与 server/package.json 一致。
2. 在普通模式获取视频格式和 PO Token，并完成一次实际下载。
3. 播放列表目前不传 Firefox Cookies；如果出现 LOGIN_REQUIRED，先检查是否在生成 Token 前就被要求登录，不要直接归咎于组件故障。后续改进见根目录《软件待办事项.txt》。
4. 打包后给绿色版文件夹改名，分别检查首次下载和再次下载。
